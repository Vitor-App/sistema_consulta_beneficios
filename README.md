# Sistema de Consulta de Benefícios

Programa simples em Java que lê os dados de um colaborador e informa sua elegibilidade para benefícios corporativos.

## Critérios usados

- Vale-alimentação: salário até R$ 3.000.
- Auxílio-creche: possui filhos e salário até R$ 4.000.
- Plano de saúde: idade a partir de 18 anos.
- Auxílio home office: modalidade de trabalho home office.
- Auxílio combustível: trabalho presencial e uso de veículo próprio.
- Participação na PLR: pelo menos 1 ano de empresa.
- Bolsa de estudos: idade até 30 anos e pelo menos 1 ano de empresa.

O projeto foi escrito com Java básico, usando apenas `Scanner`, variáveis, condições `if` e entrada pelo teclado.
